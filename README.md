# jummp

Professional Webinar & Live Broadcasting Platform built with Next.js 14, Tailwind CSS, TypeScript, and active viewport detection for desktop and mobile.

## Features
- **Responsive Viewport Detection**: Custom `useViewport` hook with real-time adaptation for Desktop, Tablet, and Mobile devices.
- **Landing Page**: Complete hero showcase, competitor comparisons, interactive feature grids, pricing calculators, and FAQs.
- **Pricing & Plans**: Flat-rate tiers (Starter & Professional) with annual/monthly savings calculator and feature comparison matrix.
- **Authentication**: Seamless Google Single Sign-On and passwordless 6-digit OTP verification.
- **Developer Documentation**: API authentication, Webhooks payloads, and secure iframe embedding guides.
- **Branded Design System**: Curated color tokens (`#0b5cff` electric blue, `#00053d` dark navy) and typography (`Plus Jakarta Sans`, `Kalam`, `Inter`).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
